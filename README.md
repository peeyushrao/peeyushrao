# Hi, I'm Peeyush 👋

I've spent 19+ years in IT, the last 8 of them in security — started out as a generalist sysadmin and ended up defending endpoints at scale in a Global SOC. These days I'm a Senior Specialist on the GSOC Security Technical Operations team at CGI, based in Bengaluru.

## What I actually do

I keep endpoints, identities, and network edges secure across a 100,000+ device CrowdStrike Falcon deployment. My sysadmin background turns out to be useful for this — when you've touched Active Directory, SIEM pipelines, and cloud proxies, you start seeing how the whole stack connects, which makes you better at spotting when something's off.

Right now I'm mostly heads-down on:

- **Endpoint defense** — running EDR/NGAV at enterprise scale with CrowdStrike Falcon
- **Zero Trust / SSE** — Zscaler ZIA and ZPA
- **Detection & response** — SIEM operations, tuning detections, handling incidents
- **Threat hunting** — IOA/ML/SVE tuning, turning threat intel into something actionable
- **Incident response** — SOC ops, escalation, working across teams to close things out

## Tools I use day to day

**Endpoint security:** CrowdStrike Falcon (Insight, Prevent, Firewall Management, Spotlight, Forensics, RTR, API) — administered at 100K+ endpoint scale. Also Trellix, formerly FireEye/McAfee (HX, NX, ePO clusters, ENS, MNE, FRP), including migrating from TAP mode to inline blocking.

**Security service edge:** Zscaler ZIA & ZPA — URL filtering, SSL inspection, sandboxing, cloud app control, ZTNA.

**SIEM/SOC:** ArcSight (correlation rules, dashboards, connector management), Splunk, and hands-on time with Microsoft Sentinel.

**Infrastructure:** Multi-domain Active Directory, VMware vSphere/vCenter, Linux administration.

## Certifications

CrowdStrike Certified Falcon Administrator (CCFA), Zscaler EDU-200, Zscaler Zero Trust Certified Associate, Microsoft SC-900 and AZ-900, Google Cloud Digital Leader, VMware VCP5, and MCSE.

## Why this repo exists

This is where I write things down while I'm still figuring them out, not after I've mastered them. Right now that's mostly security automation, detection engineering, threat hunting, and getting better at Python and PowerShell — because sooner or later every security engineer has to script something.

If sharing a fix here saves someone a 2 AM page, that's a good day.

## Outside of security

I read a lot — tech, history, whatever expands the picture. I meditate, which I've come to think of as the original incident response. And I write, mostly about tech, occasionally about everything else.

Happy to talk shop — CrowdStrike, Zscaler, SOC operations, whatever. Good conversations are underrated but they're everything.
